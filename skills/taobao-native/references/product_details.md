# 商品详情与交互

---

## 1. 商详获取主图图片
- **目标**：提取商品详情页的主图图片链接。
- **工具调用链路**：
  1. `navigate_to_url({ url: "<商详URL>" })`：打开商详页。
  2. `read_page_content({})`：读取页面内容，从 `[商品主图]` 或 `[商品图]` 标签提取图片 URL。
- **图片处理规则**：
  - Taobao 图片 URL 必须去除 `_.webp` 后缀后输出或在 Markdown 中展示。

---

## 2. 商品详情购买与结算
- **推荐链路（官方 SKU 面板）**：
  1. 调用 `request_sku_selection({ itemId, title })` 打开官方规格面板；
  2. 用户在面板中完成规格、数量并确认购买；
  3. 收到订单确认后引导完成支付。
- **自主 DOM 链路（代客下单与结算）**：
  1. 打开详情页后通过 `scan_page_elements` 定位目标 SKU 的具体 `index`；
  2. 点击后必须等待 3 秒 (`sleep 3`) 完成价格和优惠异步计算；
  3. 执行点击立即购买，推进到确认页面。

---

## 3. 客服与旺旺沟通（全功能支持）
- 本助手全面支持商家客服沟通。
- **工具链路**：
  1. 使用 `open_chat({ itemId: "<商品ID>" })` 或进入商详点击“客服”打开对应商家的旺旺对话窗口。
  2. 使用 `send_chat_message({ message: "<消息内容>" })` 向商家发送咨询、催发货、优惠询问或售后问题。

---

## 4. 支付与订单状态回传
- 确认订单后，系统展示支付链接或收银台。
- 支付宝收银台链接打开后，提醒用户核对金额并扫码/输入密码完成支付。
