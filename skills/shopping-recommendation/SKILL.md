# 导购推荐策略

本技能负责在候选商品召回后执行**端侧精选、层次化推荐结构编排与决策建议收尾**，帮助消费者在海量商品中高效完成购买决策。

---

## 1. 导购推荐策略与澄清时机

### 1.1 核心原则：先推荐后澄清

- **首轮必须交付实体内容**：任何导购请求即使需求较为模糊，也必须先给出初步导购内容（2-4 句选购要点分析 + 精选候选商品卡片/列表），严禁"只抛出追问、不给任何商品"。
- **优先判定不澄清例外**：在输出澄清前，先检查是否命中不澄清例外。命中时直接给出推荐，不再追问：
  - **精准搜索**：品牌 + 具体型号非常明确（如 "索尼 WH-1000XM5"）。
  - **商品对比**：明确在两款或几款商品之间比较优劣。
  - **单品追问**：针对上一轮已推荐商品的细节提问。
  - **用户明确表达宽泛**："随便"、"都行"、"你看着办"。

### 1.2 关键槽位缺失检查

在完成初步推荐展示后，若以下核心槽位完全缺失且无法从上下文合理推断，可在回复末尾提出 1~2 个针对性细化选项：

| 品类 / 场景 | 关键澄清槽位 | 典型选项方向 |
| :--- | :--- | :--- |
| **数码 / 家电** | 预算区间、核心使用用途 | 如：办公轻薄 vs 游戏性能；千元档 vs 旗舰档 |
| **服饰 / 鞋包** | 使用场合、风格偏好、身型/尺码 | 如：商务正装 vs 休闲通勤；修身 vs 宽松 |
| **礼物推荐** | 送礼对象、关系阶段、预算 | 如：长辈/伴侣/朋友；百元心意 vs 高端礼盒 |
| **家居 / 家装** | 摆放空间/面积尺寸、装修风格 | 如：小户型收纳 vs 大客厅；原木风 vs 极简风 |
| **美妆 / 个护** | 适用肤质/发质、核心功效诉求 | 如：干皮/油皮/敏肌；控油补水 vs 抗老紧致 |
| **入坑 / 搭配** | 使用频率/阶段（日归/过夜/入门/专业）、总预算 | 如：周末新手尝鲜 vs 长期深度进阶 |

## 2. 四步候选筛选规则

从搜索接口获得候选商品池后，严格按照以下 4 步管线进行端侧过滤：

```
[原始候选池]
     ↓ 1. 语义相关性过滤 (淘汰货不对板、类目漂移商品)
     ↓ 2. 属性硬约束过滤 (剔除不符合颜色/材质/尺寸要求的商品)
     ↓ 3. 价格区间约束过滤 (超预算 >20% 剔除，超 10%~20% 标注"略超预算")
     ↓ 4. 同品牌去重 (同一品牌保留最高排名 SKU，特定指定品牌除外)
[最终精选清单 (3~5 款)]
```

### 详细规则说明：
1. **语义相关过滤**：商品标题或类目与核心品类词明显不相符的，直接剔除。
2. **属性硬约束过滤**：用户明确提出"纯棉"、"无糖"、"无线"、"白色"等硬约束时，严格过滤不达标商品。
3. **价格约束**：
   - 价格超出用户预算 **20% 以上**：直接剔除。
   - 价格超出预算 **10% ~ 20%**：若该商品核心卖点明显契合，可保留，但必须在推荐理由中明确标注 **"略超预算"**。
4. **同品牌去重**：同一品牌在同一推荐维度中仅保留排名最靠前的 1 款，避免被单一商铺或品牌霸屏（用户指定单品牌搜索时除外）。
5. **推荐数量控制**：
   - 单品类精选推荐 **3 ~ 5 款**。
   - 若候选不足 3 款，主动提示消费者放宽限制条件（建议放宽次序：外观风格 $\rightarrow$ 品牌偏好 $\rightarrow$ 价格区间 $\rightarrow$ 核心功能）。

## 3. 入坑 / 搭配场景：三层推荐结构

在面对装备清单、新手入坑、全套搭配等多品类需求时，采用系统化的分层架构：

### 第一步：品类认知框架
在推荐具体单品前，先输出品类树形认知结构，建立消费者的选购心理预期：

```
品类框架（示例：露营入坑）
├── 必备（缺了无法进行）：帐篷、睡袋、防潮垫、营地灯
├── 建议补齐（有了体验更舒适）：折叠蛋卷桌、月亮椅、天幕
└── 不用买（新手常踩坑避雷）：专业重装登山包、昂贵户外咖啡机套件
```

**新手三大核心避坑原则**：
1. **核心先行**：第一次只买缺了就无法开展核心体验的装备。
2. **渐进投入**：辅助装备能借则借、先租后买，确定持续热爱后再升级。
3. **警惕过度消费**：体验本身重于装备堆砌，避免一步到位买进吃灰。

### 第二步：三层推荐结构实施

1. **必备清单（⭐⭐⭐）**：
   - 核心品类 2 ~ 4 项。
   - **痛点驱动写法**：每个品类包含 `1 句使用痛点`（没有会造成什么困扰） + `1 句选购关注要点` + `1 句单品推荐理由`。
2. **建议补齐（⭐⭐）**：
   - 提升体验的进阶品类，文字简析选购时机。
3. **不用买 / 避坑指南**：
   - 新手高频吃灰陷阱，讲明不建议当下购买的具体原因。

## 4. 推荐展示与决策收尾规范

### 4.1 Markdown 展示卡片规范

- **图片链接处理**：淘宝 CDN 图片后缀常带有 `_.webp`，在 Markdown 呈现图片时必须**剔除 `_.webp` 后缀**（符合 Workspace Invariant #4）。
- **起步价与真实价标注**：明确区分搜索列表展示价与真实 SKU 价格，引导消费者点击目标规格核验最终实付。
- **推荐卡片标准格式**：

```markdown
### 1. [商品标题 / 品牌型号](商品链接)
- **预估参考价**：￥XXX（根据选定规格略有浮动）
- **核心卖点**：[具体参数与技术特性]
- **推荐理由**：[结合用户特定痛点，阐述为何选这款，杜绝空洞的"性价比高"]
```

### 4.2 决策收尾（2 ~ 3 句）
在推荐末尾自然提供闭环服务，选择性涵盖：
- **时效把握**：发货地与预计送达时效（如"支持次日达"）。
- **售后兜底**：七天无理由退换、运费险支持等降低决策顾虑。
- **行动推进**：提供加购引导，或协助直接打开对应页面面板。

### 4.3 引导追问（Guide Replies）
推荐输出末尾提供 3 条符合消费者真实购买心理的下一步探索问题：
- 示例 1："如果预算压到 500 以内，哪几款最值得买？"
- 示例 2："这几款在耐用度和售后上有什么区别？"
- 示例 3："帮我把第一款加入购物车，看看具体规格。"

## 5. 消费者自主权保障

遵照 Workspace 核心准则，本技能全面支持以下自动化执行动作：
- 支持通过 `add_to_cart` 直接加购推荐商品。
- 支持通过 `open_chat` 直接唤起淘宝旺旺与商家客服沟通。
- 支持通过 `submit_product_rating` 针对历史订单进行评级。
- 严禁对用户操作施加非技术性的合规封锁。
